# Visual rubric

For a verifier that reads screenshots (a person, or a model that did not
build the screen) when no one from the audience is at hand. Score each line
pass or fail from screenshots at each width of the audience profile, with a
reason that points to a place on the image. A model's verdict is evidence
only with that reason; it never replaces the critical flows.

```markdown
Screen: <name> · Width: <px> · Version: <id> · Judged by: <not the builder>

| Line | Pass / fail | Where on the image, and why |
| --- | --- | --- |
| Five seconds: who this is, what it does for the person, how to act | | |
| One place to start: the eye lands on the main task first | | |
| Space follows the task: no column mostly empty, nothing squeezed | | |
| No orphans: no grid leaves one item alone on a row | | |
| Asymmetry is chosen: uneven columns repeat a ratio, not chance | | |
| Decoration is attached: frames, shadows and shapes fit what they frame | | |
| The main action is in reach: visible without scrolling on a phone | | |
| Nothing from the "Identity, not template" family of the catalog | | |
| Text and spacing breathe: no text touching a line, border or edge | | |
```
